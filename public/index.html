Everything you check before enrolling, in one window.

Search a course once and BYE gathers what you'd normally collect across a dozen tabs.

01

Course search

Type a code like math 5a to see every section, its schedule and format, and who teaches it. Filter for fully online classes.

02

Professor comparison

Overall rating, difficulty, number of ratings and "would take again" side by side, sortable the way you want.

03

Student reviews

Read reviews for the course you're taking, or from the professor's other courses, with links to the original source.

04

Review summaries Experimental

On supported Macs, BYE highlights recurring positives and concerns using Apple's on-device AI. Nothing is sent to a cloud AI, and the original reviews stay one click away.

Install in a minute.

  1. Download the AppleSilicon.dmg file from the latest release.
  2. Open the downloaded DMG.
  3. Drag BYE into your Applications folder.
  4. Eject the DMG and open BYE from Applications.
Seeing a security warning?

BYE is signed but not yet notarized by Apple, so macOS may block the first launch. If you trust the download, go to System Settings → Privacy & Security and choose Open Anyway.
