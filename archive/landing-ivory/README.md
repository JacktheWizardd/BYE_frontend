It includes the "Web demo" wording change. Kept so it can be restored or improved later.

- `index.html`, `styles.css`, `404.html` were served from `public/`.
- They load fonts from `/fonts/` and images from `/favicon.png` and `/apple-touch-icon.png`, which stay in `public/`.
- To restore: copy these three files back into `public/` (and remove the generated landing build).
